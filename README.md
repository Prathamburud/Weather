# 🌦️ Weather Application

A simple weather application built using **HTML, CSS, and JavaScript**.

## Features

- Search weather by city
- Shows temperature
- Shows humidity
- Shows wind speed
- Shows weather condition
- Displays error for invalid city

## Technologies Used

- HTML
- CSS
- JavaScript
- OpenWeatherMap API

## Project Structure

```text
Weather-Application/
├── weather.html
├── weather.css
├── weather.js
├── search.png
├── heavy-rain.png
├── humidity.png
└── smoke.png
```


## How to Run

1. Download or clone the project.
2. Add your OpenWeatherMap API key in `weather.js`.
3. Open `weather.html` in your browser.
