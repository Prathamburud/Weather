# 🌦️ Weather Application

A simple weather application built using **HTML, CSS, and JavaScript**.

## Features

- Search weather by city
- Shows temperature
- Shows humidity
- Shows wind speed
- Shows weather condition
- Displays error for invalid city

## Technologies Used

- HTML
- CSS
- JavaScript
- OpenWeatherMap API
